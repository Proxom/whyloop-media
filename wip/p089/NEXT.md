topic key: hook and loop (synonyms: velcro, hook-and-loop fastener, touch fastener) - not in learnings/topics-used.md (checked all rows; zipper = interlocking teeth + slider, a different mechanism; no ratchet / latch / rack).
Principle: stiff hooks on one tape catch loops on the other (mechanical, no glue); a pull along the tapes (shear) is shared by every engaged hook, so it holds hard; peeling puts the load only on the row of hooks at the moving edge, which straighten and let go one row at a time, so it opens easily.
Built from kit/kit.js (makeKit, materials, backdrop, lightRig, glow, TXT) + scene-local: MACRO = blue loop tape (superellipse loop arches, 3 hook rows + 3 decorative rows in between), white top tape as a bending ribbon (peel curve), 21 x 3 white nylon J hooks (stem 8 + 220 deg arc, straighten parameter b); OUTSIDE (x 5000, mm) = canvas bag flap, blue loop patch with stitches, white hook strap peeling with the same curve.
