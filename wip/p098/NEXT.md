topic key: fuel gauge (synonyms: fuel level sender, float sender, gas gauge, sending unit) - not in learnings/topics-used.md (coordinator checked 89 rows; p077 fuel nozzle shut-off never published, different mechanism).
Principle (HowStuffWorks + Delphi): float on a pivoted arm -> wiper on a resistive strip grounded at one end; full = wiper near ground = low resistance = more current = needle F; level drops -> wiper moves away -> more resistance -> less current -> needle toward E. One idea: float -> wiper -> resistance -> needle. Some makes are reversed (said in the first comment).
Built from kit/kit.js (makeKit, materials, backdrop, lightRig, glow, TXT, S.tag/outlined) + scene-local: tank back half as extruded slabs (red hatched cut faces at z=0, galvanised walls, back plate, seam flanges), filler neck, translucent fuel box + surface, sender (black flange, brass terminal, steel tube), ceramic card + dark resistive strip sector, brass rivet + black ground wire, brass hub, steel arm + pin, brass wiper, white float (RoundedBox); dash gauge at x=3000 (canvas face E/1/2/F + pump icon, chrome bezel, orange needle, dash hood). 2D overlays: inset gauge (needle = kin), red wire from the terminal, current dots (speed = current), green short path / red long path highlight on the strip.
kin.py (120 Hz): PASS - float never touches the card (min 68.9 mm), the sender tube (136.7 mm) or the tank walls/floor (min 4.0 mm at empty); wiper always on the strip; needle changes only when the arm moves, arm only when the level changes, level rises only while fuel pours in; loop ends full (needle F). R linear 10 (full) -> 73 ohm (empty), gauge 20 ohm, current at empty = 0.32 x full.
Story: hook 0-2.15 s dash gauge, needle F -> E (payoff flash) + question + red circle on E; 1 wide cut tank: FLOAT, ARM, HINGE, FUEL; 2 macro card: WIPER, RESISTOR STRIP, SHORT PATH (green), TO GROUND; 3 wide: fuel drains (SPED UP), float sinks, WIPER SLIDES, inset NEEDLE DROPS; 4 macro: LONG PATH (red), MORE RESISTANCE, LESS CURRENT (dots slower); 5 wide: fuel pours in, float rises, BACK TO FULL; outside gauge at F + answer card "A FLOAT + A RESISTOR / MOVE THE NEEDLE" + follow line; loops (needle F both ends).
